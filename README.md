# 📊 GA4 SQL Practice

This project showcases SQL exercises using the Google Analytics 4 BigQuery export, focusing on essential analytical skills and real business questions.

🔧 **Techniques Practiced**

CTEs to structure complex logic (conversion funnels, rankings, time-series prep)

UNNEST to extract nested GA4 fields (event_params, items)

Window functions for rankings, cumulative totals, and average revenue by segment

**📈 Business Questions Explored**

Conversion funnel performance by device category 

Top landing pages by add_to_cart events and by daily traffic

Event distribution across device categories and countries

Daily country rankings based on total events

Cumulative event trends over time by device

E-commerce insights, including average revenue per device and top products by country

Session engagement rates per country and device category
